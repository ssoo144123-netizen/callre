# DialerTheme

اپ مخاطبین، شماره‌گیر، تاریخچه تماس و صفحه تماس ورودی/خروجی با تم‌های رنگی و نئونی (اندروید ۶+).

- صفحه‌کلید داخل تماس (DTMF) از دکمه‌ی «صفحه‌کلید» در صفحه تماس
- نوار سبز «بازگشت به تماس» با زمان زنده در بالای برنامه
- زمان تماس در نوتیفیکیشن تماس هم نمایش داده می‌شود

ساخت APK: GitHub Actions ← Build APK، یا Android Studio.
